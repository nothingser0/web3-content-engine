## FRAMING GUIDE - Personal Story Conversion

⚠️ **MANUAL MODE ONLY** - This guide applies when first-person input detected (run_manual.py). 
BATCH MODE avoids personal stories entirely to prevent fake claims.

**Philosophy:** Personal story = Authority builder. Framework/lesson = Deliverable.

**When to use Honest Journey angles:**
- You have first-person input (user explicitly shares personal experience)
- Story has clear lesson/framework that can be extracted
- Experience is relatable and audience can apply the framework

**Structure Template for Honest Journey angles:**
1. **Hook (personal):** Lead with result/impact
   - If user explicitly said it: "Aku rugi 3 bulan gara-gara..."
   - If user explicitly said it: "50+ campaign later, aku akhirnya ngerti..."
   - If user explicitly said it: "Dari trial & error, aku develop framework ini..."

2. **Body (educational):** Extract lesson + framework
   - What happened (brief story)
   - Why it matters (lesson learned)
   - What framework to apply (actionable takeaway)

3. **Closing (actionable):** Give replicable framework
   - Checklist format
   - Red flags list
   - Decision criteria
   - Step-by-step workflow

4. **CTA (community):** Engagement based on shared experience
   - "Kamu pernah ngalamin hal serupa? Share pengalaman kamu"
   - "Mana checklist yang paling penting menurutmu?"
   - "Ada yang mau nambahin red flag lain?"

**Framework Extraction Methods:**
- **Checklist method:** "5 Hal yang Harus Dicek Sebelum..."
- **Red flags method:** "X Red Flags yang Harusnya Aku Notice"
- **Criteria method:** "Filtering Criteria yang Aku Pakai Sekarang"
- **Workflow method:** "Framework Evaluasi yang Aku Develop"
- **Before/After method:** "Dulu vs Sekarang: Perubahan Approach"

**Quality Check - Does your Honest Journey angle have:**
- ✅ Clear framework/checklist that others can use?
- ✅ Actionable takeaway beyond the story?
- ✅ Educational value (not just entertainment)?
- ✅ Replicable methodology?
- ❌ Pure storytelling without lesson? (REVISE)
- ❌ Flex/bragging without framework? (REVISE)

**Example transformations:**
- If source says "Aku pernah JP $5k" → Framework: "Aku JP $5k - Framework Evaluasi yang Bikin Gw Yakin"
- If source says "Aku sering salah" → Framework: "Trial & Error 50+ Campaign - Checklist yang Sekarang Aku Pakai"
- If source says "Sekarang lebih selektif" → Framework: "Dari Ikut Semua ke Pilih yang Worth - Filtering Criteria"

## AVAILABLE FORMATS
Pilih 2-3 format yang paling cocok untuk setiap angle:

1. **Single Tweet** - Quick take, hot take, atau statement singkat (max 280 char)
2. **Thread** - Story telling, tutorial step-by-step, deep dive (8-12 tweets)
3. **Image** - Visual breakdown, listicle, comparison (max 4 slides/cards)
4. **Poll** - Engagement tinggi, survey, opinion gathering (4 options)

**Format Selection Guide**:
- Personal story → Thread, Single Tweet
- Quick tip/hot take → Single Tweet, Poll
- Data/statistics → Image, Thread
- Tutorial → Thread, Image
- Controversial opinion → Single Tweet, Thread, Poll
- Deep analysis → Thread, Image

- `evergreen_score` (1-10): Seberapa timeless? 10 = valid 1+ year, 6-7 = valid 3-6 months
- `evergreen_category`: Security & Scams / Fundamental Skills / Tool Reviews / Case Studies / Mindset & Strategy
- `content_pillar`: Masuk bucket brand mana? (Honest Opportunity Results / Mistakes & Lessons / Worth vs Skip Filters / Tools & Workflows / Trending Quick Takes)

- "Campaign Viral Aku Skip - Ini Reasoning"
- "Red Flags Aku Miss - Rugi $50 Gara-Gara Ini"

❌ **Bad (AI slop - AVOID):**
- "Complete Guide to Testnets: Everything You Need to Know"

- "10 Game-Changing Tips for Campaign Selection"

- Use real numbers when relevant ($47 not $50)

- Sound like casual conversation, not tutorial
- Under 80 chars for titles

- Include variety across all 10 angles (don't suggest Thread for everything)
